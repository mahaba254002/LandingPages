## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed if you are exploring the React/Next.js versions.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mahaba/LandingPages.git
   ```

2. **Navigate to a specific project folder:**
   ```bash
   cd LandingPages/VistaLandingPage
   ```

3. **Open the project:**
   - For HTML/CSS: Open `index.html` in your browser.
   - For React/Next.js:
     ```bash
     npm install
     npm run dev
     ```
